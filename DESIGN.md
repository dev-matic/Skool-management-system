# Design

## Overview

The approved design system lives in
[docs/design-system.md](docs/design-system.md). It is the single source of
truth for colours, typography, spacing, icons, components and print rules.
Read it in full before any design critique, audit, polish or UI change, and
judge screens against it.

This file only points there, so the rules are never kept in two places. Do not
copy tokens into this file. Changes to the design system need the owner's
approval (see CLAUDE.md).
